# 从 PPT 生成教案

用户给的是自己做好的课件时走这条路。**目标不是把幻灯片文字搬进表格，而是从"呈现了什么"反推出"老师怎么教、学生怎么学"，再补上 PPT 里天然缺的三样东西：学生活动、设计意图、教学环节的台阶。**

---

## 一、读到什么

1. 用 office 工具打开并逐页读取课件，拿到每一页的形状与文字（标题、正文、图注、表格、备注）。用户同时给了课件原件和讲稿时，讲稿优先。
2. 逐页记下四类信息：
   - **标题**：这一页在讲什么；
   - **要点文字**：结论、定义、公式、数据；
   - **图像/表格/视频/动画**：出现了什么素材（图片本身的内容往往读不到，只看到形状名时按标题判断，判断不了就问）；
   - **设问句**：以"？"结尾或明显是问题的句子——这些是教案里最值钱的部分。
3. 读不到的东西（图片内容、动画顺序、口头补充）不要猜，列成问题问用户。

## 二、先归并，再动笔

### 第 1 步：页 → 活动
一页通常等于一个课堂活动。内容极短的两三页（封面、过渡页）合并或跳过。

### 第 2 步：活动 → 环节
把活动按认知台阶归并成 3–5 个环节（默认 4 个）。归并标准是"这一组活动共同完成一个台阶"，不是"页码平均分"。

### 第 3 步：给环节起名
两段动宾短语，如「情境导入，建立模型」「模型运用，微观探究」。名字要能看出这个环节在推进什么，不要用「环节一：新课」。

## 三、逆向映射表

| PPT 上的东西 | 落到教案哪里 | 注意 |
|---|---|---|
| 封面/标题页 | 文档标题 + 教学内容分析的首句出处 | 补教材版本、章节、课时 |
| 情境图、视频、新闻、生活现象 | 教师【引入】【展示】 | 学生侧补【观察】【思考】 |
| 设问句 | 教师【提问】/【追问】 | **必须**配学生【回答】/【讨论】，PPT 里没有答案就在这里补 |
| 定义、结论、公式页 | 教师【讲解】/【总结】 | 压成一句教师的话，不要整页抄 |
| 图表、曲线、分子结构、静电势图 | 教师【展示】【支架】；学生【读图分析】 | 说清"让学生从图里看出什么" |
| 实验步骤、演示实验 | 教师【演示】/【活动】；学生【观察】【记录】 | 补安全提示与现象描述 |
| 例题、练习 | 教师【提问】；学生【计算】/【作答】/【书写】 | 题干可精简，保留数据 |
| 知识梳理、思维导图页 | 教师【总结】；学生【总结】 | 不要照抄整棵图，写归纳路径 |
| 过渡页 | 教师【过渡】 | 承接上环节、引出下环节 |

## 四、必须补全的部分

PPT 里通常没有，但教案里必须有：

1. **学生活动**：每一处教师提问都要有学生的思考与回答，不能只有教师独白。
2. **设计意图**：每环节 1–3 段，按"学科理解／学生认知／素养能力"三角度写，不能复述活动本身。
3. **环节台阶**：PPT 是内容顺序，教案要的是认知顺序——可能需要调整页序、合并页、补一页口头的衔接。
4. **学情与重难点**：从课件内容反推学生容易卡住的地方，写进「学习者分析」和「教学难点」。
5. **课标**：课件里一般没有课标原文。**向用户索取**，拿不到就留「（课标原文待补）」，不得自行编写。
6. **教材依据**：课件不等于教材。教材分析要按教材的板块顺序写，不能把课件的页序当成教材的逻辑；两者不一致时以教材为主，并在还原说明里指出差异。没有教材目录或页面时向用户索取，或标注「（依据教材目录整理，栏目与实验编号待核对）」。

## 五、顺序红线

**环节的划分与顺序必须跟课件的页序走**，不得按内容性质重新归类。判断依据只有页码：这一页在课件里排第几，它就属于第几个环节。

典型错误：把课件中排在“钠与氧气的实验”之后的“为什么保存在煤油里”“久置空气中最终变成什么”当成“性质应用”，挪到最后一节——它们本来就是该环节的实验延伸。同理，“钠着火能否用水灭火”在第 12 页，属于钠与水那一环节，不属于用途。

## 六、动笔顺序

1. 先读 PPT，列一张「页 → 活动 → 环节」对照表，给用户看一眼（5–10 行即可），确认没理解偏。
2. 再按 `教案结构.md` 写六部分正文。
3. 最后写教学过程的四列表格。

## 六、交付时附一份「还原说明」

放在教案后面单独一段（不写进正文），3–5 行：

- 共用了课件多少页，合并成了哪几个环节；
- 哪些页没有采用、为什么（内容重复、属于拓展、与本课目标无关）；
- 哪些内容是我按学科常识补的，需要用户核对（尤其是图像内容、实验现象、数据）；
- 有哪些信息还缺（课标、课时长度、班级学情）。

## 七、不要做的事

- 不要一页幻灯片配一条教案条目——教案的行是环节，不是页。
- 不要把课件上的陈述句整段搬进【讲解】，教案要的是教师口头语言，比课件短。
- 不要把课件里便于记忆的口号、口诀、单字缩写（如把实验现象压缩成"浮熔游响红"）搬进教师活动或学生活动。课件可以这么呈现，教案不行：教案要写完整描述，并给每条现象配上证据与解释。
- 不要为课件里没有的学生活动编造"小组讨论"，那会让流程和真实课堂对不上；宁可写【思考】【回答】。
- 不要默认课件顺序就是教学顺序；有疑问就问。
