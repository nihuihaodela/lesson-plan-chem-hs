# 知识库：让没有教材和课标的人也能写出可核验的分析

## 要解决的问题

写教案必须回答两个"有什么依据"的问题：课标对这块内容要求什么，教材是怎么编排的。如果使用者手上没有课标和教材，模型容易凭训练记忆编造——写出看起来像引文、实际不存在的条目。本库就是消除这个风险的办法：**把权威文本压缩成条目，随 skill 一起分发；模型只允许引用库里的条目，库里没有就明说没有。**

## 三条硬规则

1. **只引用"已核验"条目。** 每条都有状态：`已核验` / `待核验` / `待录入`。引用 `待核验` 条目必须标注「（待核验）」，引用 `待录入` 等于引用不存在。
2. **逐字复制，不改写。** 引文必须是该条目原文的连续片段，不得概括、拼接或"换个说法更像课标"。要改写就说明是教学解读，并与之分句。
3. **库里没有，就说没有。** 写成「（未收录，需用户提供原文）」，不得用学科常识替代，不得推断"课标大概会要求……"。

## 引用语法

写进教案正文时，**不标条目号、不加「」〔〕**，引文直接写进句子；条目号只记在交付说明的核验表里，供人抽查。下面是为了说明对应关系才并列出来的：

> 课标对该部分的要求如下：「认识离子反应及其发生的条件，能正确书写离子方程式。」〔K-B2-2.3〕

交付时附一张**引用核验表**：引文 → 条目号 → 出处 → 状态，让人能逐条抽查。

## 编号规则

| 前缀 | 含义 | 例 |
|---|---|---|
| `K-S` | 学科核心素养 | `K-S3` 证据推理与模型认知 |
| `K-G` | 课程目标 | `K-G1` 第 1 条课程目标 |
| `K-B{主题}` | 必修内容 | `K-B2-2.3` 必修主题2 内容要求 2.3 |
| `K-B{主题}-P{n}` | 必修教学提示 | `K-B1-P2` 学习活动建议 |
| `K-B{主题}-X{n}` | 必修学业要求 | `K-B5-X7` 第 7 条 |
| `K-X{模块}-0` | 选择性必修模块总述 | `K-X1-0` |
| `K-X{模块}-{主题}-…` | 选择性必修内容 | `K-X1-2.1`、`K-X3-2-P3`、`K-X2-1-X4` |

## 数据是怎么保证不出错的

不是靠肉眼校对，是脚本：

1. **录入即生成**。源文本（`_src/*.txt`，用户提供的课标文字）→ 脚本切分成条目 → 生成 markdown。没有手抄环节。
2. **全文重建校验**。把所有条目按原文顺序、连同标题拼回去，与源文本逐字比对，多一个字、少一个字、错一个位置都会报错。
3. **上下标折叠比对**。`Fe³⁺` 这类按原书还原的写法，比对时折回 `Fe3+` 再比，所以"还原"和"逐字一致"同时成立。
4. **结构自检**。每个主题的「内容要求／教学提示／学业要求」三块必须都切出来，缺一块直接报错——防止标记词不匹配时整块被吞。
5. **出处一致性**。条目号里的模块/主题编号必须与 `出处` 字段一致。

这三道都过了才写入。任何一道不过，文件不生成。

## 怎么扩充

- **新主题**：在 `_src/` 放一个文本文件，跑脚本重建。
- **教材库**：按 `教材-必修第一册.md` 的模板填，一节一条，标 `待核验`，核对后转 `已核验`。
- **修订**：只追加，不覆盖；旧条目保留但标注被谁替代。

## 教材原文（受版权保护）

`教材原文/` 下是人民教育出版社教材的全文 Markdown，**只用于本机检索，不得提交到公开仓库**；skill 根目录的 `.gitignore` 已排除该目录。开源分发时，教材依据只保留 `教材-必修第一册.md` 里的结构化摘要（栏目名、实验编号、图号），不含原文。
