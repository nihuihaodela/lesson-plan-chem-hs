# 写作规则

## 一、教学目标

### 条数与结构
3–5 条，看教学流程有几个板块。一个板块一般对应一条目标；目标条数与环节数差 1 以内是正常的，不要为凑数而拆或并。

### 主语
**主语是学生，而且通常省略。** 每条以行为条件或行为动词开头，读起来默认是"学生能……"。

- 合格：`结合具体实例分析，掌握氢键的本质、成因和特点`
- 合格：`通过测量元素立方体的物理量并计算模型原子数，学会依据实验数据进行逻辑推演`
- 不合格：`使学生掌握氢键的本质`（教师主语）
- 不合格：`培养学生证据推理素养`（教师行为 + 空话）

禁用：使学生、让学生、培养学生、引导学生、提高学生、激发学生、帮助学生。

### 句式
`〔行为条件：通过／结合／基于……〕，〔行为动词〕〔内容〕，〔体验或观念落点〕`

三段可以只写两段，但**必须有一个可观测的行为动词**；体验性动词（体会、树立、形成）只能收尾，不能单独撑起一条目标。

示例：`通过分析钠的原子结构示意图，预测钠可能发生的反应，初步建立“结构决定性质”的分析视角。`

### 行为动词分层（选用时按层次排布）

**认知性目标**
- 低层次：知道、说出、识别、描述、举例、列举、了解、认识、辨认、区分、比较
- 高层次：理解、解释、说明、判断、预期、分类、归纳、概述、应用、设计、评价、使用、解决、验证、证明

**技能性目标**
- 低层次：初步学习、模拟、能表示、初步学会、完成
- 高层次：学会、掌握、迁移、灵活运用

**体验性目标**
- 低层次：感受、经历、尝试、体验、交流、合作、认同、体会
- 高层次：形成、养成、具有、树立、建立、保持、发展、增强

使用要点：

1. **一节 45 分钟的新授课，动词层次应当从低往高排布**：知道/描述 → 说明/解释 → 应用/设计 → 形成/树立。四条都写成"掌握""理解"是层次塌陷。
2. 动词要和内容匹配：概念课前期用"说出、描述、辨认"，中段用"解释、归纳"，收尾用"应用、设计"。
3. 体验性动词必须带具体内容，不能空转：`体会性质决定用途的观念` 可以，`体会化学之美` 不行。
4. **目标要有概括性**：一条目标覆盖一个教学板块，不写实验操作细节。`描述钠与水反应的现象并解释其成因` 合格；`能说出钠浮在水面、熔成小球、四处游动……` 是把课堂细节抄进了目标。

### 素养怎么放
不按五条核心素养分条罗列（写成"1、宏观辨识……2、证据推理……"是最常见的错误）。每条目标只承载 1–2 个素养，融进行为与内容里，必要时句尾补一句观念落点。

五条核心素养（用于自查，不要直接抄进目标）：宏观辨识与微观探析、变化观念与平衡思想、证据推理与模型认知、科学探究与创新意识、科学态度与社会责任。

## 二、教学重难点

**一律用名词性短语概括，不写成句子。** 重点写"教什么"，难点写"难在哪"。

| 合格 | 不合格 |
|---|---|
| 钠与水的反应 | 通过实验探究钠与水的反应，掌握其化学方程式 |
| 钠与水的反应现象成因解释 | 学生很难理解钠为什么会浮在水面上 |
| 离子方程式的书写 | 学会正确书写离子方程式并能判断物质是否拆分 |
| 钠与盐溶液的反应 | 钠投入硫酸铜溶液中不能置换出铜 |

- 重点 ≤4 个，用「；」并列。
- 难点 1–2 个，必须与「学习者分析」的不足同源。
- 难点不能写成"学生基础薄弱""学生计算能力差"——那是学情，不是本课难点。

## 三、环节设计

- 默认 4 个；用户指定 3 个或 5 个就照办。3 个适合单点突破的短课时，5 个适合实验探究或两轮应用的内容。
- 每个环节承担一个不同的认知台阶，推荐序列：情境与矛盾 → 概念建构 → 应用迁移 → 总结提升。
- 环节名：两段动宾短语，中间用「，」。参考「创设认知矛盾，基于图像思考」「模型运用，微观探究」。不要写成「环节一：引入」「环节二：新课讲授」这种没有信息量的名字。
- 时间（仅当用户要求）：各环节合计等于课时长度，导入不超过 8 分钟，练习与总结留够 10 分钟。写在环节名后的括号中。

---

## 四、教师活动标签

条目格式：`【标签】内容`。标签说明这一句是**教师的哪种课堂行为**，同类行为反复出现就重复使用同一标签。

| 标签 | 用在 |
|---|---|
| 【引入】 | 情境、素材、生活现象进入课堂 |
| 【展示】 | 出示图片、图表、视频、实物、资料 |
| 【提问】 | 单点提问，一问一答 |
| 【追问】 | 在学生回答后再深一层 |
| 【支架】 | 给方法、给图、给表格、给类比，帮学生迈过障碍 |
| 【创设矛盾】 | 制造与旧知冲突的现象，逼出新问题 |
| 【联系旧知】 | 唤起先前学过的概念 |
| 【讲授】 | 短促的直讲，一两句话 |
| 【讲解】 | 成段讲概念、原理、推导 |
| 【活动】 | 学生动手（测量、分组、拼接、实验） |
| 【演示】 | 教师演示实验或软件操作 |
| 【过渡】 | 环节之间、问题之间的衔接 |
| 【符号表征】 | 写化学式、方程式、离子符号 |
| 【板书】 | 明确要写在黑板上的内容 |
| 【总结】 | 收束本环节或全课 |

标签可以按课堂实际扩充，但必须是**动词性、能对应教师行为**的动作，不要自造「【重点】」「【素养】」这类名词标签。

## 五、学生活动标签

| 标签 | 用在 |
|---|---|
| 【思考】 | 面对问题先想 |
| 【回答】 | 说出结论（对应教师【提问】【追问】） |
| 【讨论】 | 同桌或小组交换意见 |
| 【推断】 | 基于已有信息做逻辑推进 |
| 【推导】 | 公式或关系式的变形 |
| 【计算】 | 定量运算 |
| 【测量计算】 | 先测后算 |
| 【观察】 | 看实验或图像 |
| 【记录】 | 填表、记数据 |
| 【书写】 | 写方程式、示意图 |
| 【设计】 | 画出或描述装置、方案 |
| 【猜测】 | 未经验证的预判（后面要接验证） |
| 【理解】 | 接受并内化一个结论 |
| 【总结】 | 学生自己归纳 |

**对位规则**：教师列每有一个【提问】【追问】【支架】【活动】【演示】，学生列必须在同一位置有对应条目；反过来，学生列不应出现教师列没有引发来源的活动。用空段落错位对齐。

## 六、设计意图

- 每环节 1–3 段，每段一个角度，不要一段里塞三个角度。
- 三个可用角度：**学科理解**（这个知识点本身的难点，为什么这样呈现更接近学科本质）、**学生认知**（调用了什么经验、绕过了什么障碍）、**素养与能力**（完成了哪种思维动作）。
- 推荐句式：
  - `通过……，引导学生……，培养……的核心素养。`
  - `……由学生自己计算得出，而非直接告知，体现……。`
  - `先给出……，让学生通过已有知识进行推理，侧重分析“为什么”，而不是简单告知“是什么”。`
- **禁止**：复述教师活动（"教师提问，学生回答"）、写"激发学习兴趣""调动积极性"这类没有落点的话。

## 七、学习者分析的写法

**一段，200–300 字**，三个层次压进同一段，顺序固定。**只分析学生，不写本课怎么做。**

1. **已经掌握了什么**：点名具体的先修知识，2–3 项，不要写"基础较好"。
2. **一句范畴定位**：这块知识在学科里属于什么范畴、处于什么地位、对后续学习起什么作用。**这一句是整段的骨架，必须有。**
3. **方法层面的不足**：写宏观的能力、观念、习惯问题，**不写本课课堂里的具体细节**。

### 范畴定位句的范式

> 氢键是分子间作用力的一种，属于超分子化学范畴。
> 物质的量是国际单位制中的七个基本物理量之一，属于化学计量学的核心范畴。
> 钠是学生进入高中后系统学习的第一种金属元素，属于元素化合物知识的开端，对后续铁、铝、铜的学习具有方法论上的示范作用。

### 不足怎么写

写"方法"不写"知识点"：

- 可以写：微粒观尚未真正建立、证据意识薄弱、对条件改变导致产物改变缺乏敏感、难以把性质迁移到陌生情境、习惯用结论解释现象而不是用现象支撑结论。
- 不要写：上课时学生会误以为钠浮起来是因为密度小、学生会写错离子方程式——这是本课的具体错点，属于「教学难点」，不该出现在学习者分析里。

### 为什么不写对策

学习者分析回答“学生现在是什么样”，不回答“我准备怎么办”。写了「本课据此以……开场，再以……追问」，就等于把教学过程的环节提前交代了，与「五、教学过程」重复，也让这一节臃肿。对策应当出现在教学过程与设计意图里。

## 八、教材分析的写法

**两段，合计 250–350 字。重心是思路的建构，不是逐点罗列。**

### 依据

教材分析必须建立在教材本身之上。可用依据：教材原文、目录与栏目结构。**没有依据时向用户索取，或标注「（依据教材目录整理，栏目与实验编号待核对）」，不得凭印象编造板块顺序、栏目名、实验编号与页码。**

### 第一段：教材写了什么、如何组织

1. 一句总述，概括本节的组织逻辑（如「能级顺序—构造原理—排布规则」）。
2. 按板块说清教材先给什么、再给什么，板块之间靠什么衔接。
3. 段落要连贯，不写成小标题。

**不要逐点复述**：不展开实验操作步骤、不罗列现象清单、不逐个点名栏目。判断标准——把这句话里的实验换成同节的另一个实验，如果照样成立，说明写的是思路；必须原样照搬才成立，说明写得太细了。

### 第二段：对教学的启示

由第一段的结构推出教学应当如何组织这些知识：先做什么、后做什么、哪里需要补充、哪里适合让学生自己走。

- 写"为什么这样组织"，不是把教材板块再复述一遍；
- 不要写成"第一步讲A、第二步讲B"的流程抄本，那是教学过程的活；
- 与「五、教学过程」不能重复。

### 两条红线

**不评价教材好坏**，不写「教材表述简略」「教材存在不足」，也不写贬义判断。

**不超长**。写满一段就停，宁可少写两句，也不要为了显得充分而堆板块。

## 九、行文语气（反 AI 味）

### 禁止（套话与 AI 味）
- **「一是……二是……三是……」式罗列**。改成「主要集中在 A、B、C 上。首先……其次……再次……」。
- 套话：值得注意的是、综上所述、总而言之、不仅……而且（连用）、极大地、非常关键、具有十分重要的意义。
- 对读者说话：我们可以看到、让我们、接下来我们。
- 无证据的评价：设计巧妙、效果良好、学生兴趣浓厚、课堂气氛活跃。
- 同义反复：通过实验探究，探究了……；通过分析，进行了分析。
- 名词堆叠的长定语：以培养学生核心素养为导向的基于真实情境的……（拆成两句）。

### 禁止（口语化）

教案的分析与说明性文字必须是书面语，简洁、平实、克制。**口语只能出现在教师活动的引号内**（那是课堂上要说的话），不得出现在教学内容分析、学习者分析、教学目标、重难点、设计意图、还原说明里。

| 口语写法 | 改成 |
|---|---|
| 本节课的处理重点放在“为什么”上 | 本节课的处理重点为反应实质的探究 |
| 却说不清每一条现象的来历 | 却无法厘清现象背后的本质 |
| 先得弄清楚钠到底是一种什么样的金属 | 需要先明确钠的结构与性质特征 |
| 学生能顺口背出现象 | 学生能够复述现象 |
| 还停留在口号上，很少真的从……出发 | 多停留于概念层面，较少依据……进行推断 |
| 习惯于用现成的结论去解释现象 | 倾向于以既有结论解释现象 |
| 难以把……迁移到生产、保存、运输这些情境里 | 难以将……迁移至生产、保存与运输等真实情境 |
| 把想当然的归因打破 | 纠正直觉归因 |
| 收束 | 作结／归纳 |
| 条件一变，产物随之改变 | 同一反应物在不同条件下生成不同产物 |
| 顺着它把重心放在…… | 顺应该逻辑，将重心置于…… |
| 亲手去验证 | 通过实验验证 |
| 拿结论解释现象 | 用结论解释现象 |
| 用一句话说清楚 | 概述 |

其他口语标记一并禁止：语气词（呢、吧、啊、嘛）、设问句（"那到底为什么呢？"）、比喻与调侃、破折号插入语、第一人称"我们"。

### 禁止（分号与冒号）

**适用范围**：分析与说明性文字（教学内容分析、学习者分析、设计意图、教学目标、重难点、还原说明）。教材栏目名在分析文字里用引号（“探究”“思考与讨论”），不用【】；【】只用于教学过程的师生活动标签。教师活动引号内的课堂用语保留自然的冒号（如「【展示】资料：……」），条款末尾的分号也保留。

**句中尽量不用分号，也不用冒号引出。** 并列的意思就断成两句，用句号；顺承或补充的就用逗号。分号与冒号只保留三种必要场合：

| 保留 | 例子 |
|---|---|
| 条款末尾的分号 | 教学目标「1、……；2、……」、重难点「……；……」 |
| 引用条目号 | 「原文」〔K-B2-2.4〕 |
| 引出引文 | 「……中对××的内容要求如下：……」（引文直接接在冒号后，不加引号符号） |
| 栏目标签 | 【预测】、【实验】、【结论】 |

其他情况一律改写：

| 不合格 | 合格 |
|---|---|
| 先由原子结构推出强还原性；再让学生验证；随后转入钠与水 | 先由原子结构推出强还原性。接着让学生验证。随后转入钠与水 |
| 课标的要求可以理解为两个方面：一是……二是…… | 课标的要求可以理解为两个方面。一是……二是…… |
| 本课把重心放在现象与成因之间：不把现象处理成短语 | 本课把重心放在现象与成因之间，不把现象处理成短语 |

判断办法：一句话里出现两个以上分号，基本就是该断句了；出现冒号时，先问「这是不是列清单」，不是就不用。

### 引文怎么写

课标引文直接写进句子，**不加「」『』这类符号，也不在正文标条目号**。条目号只出现在交付说明的核验表里，供人抽查，不进入教案正文。

> 课标对该部分的要求如下：结合真实情境中的应用实例或通过实验探究，了解钠、铁及其重要化合物的主要性质……

交付时附核验表：引文 → 条目号 → 出处 → 状态。


### 少用引号

引号只用于三种情况：引用课标或教材的原文、真正的专有名称、人物对话。**同一段里引号不超过两处**。

不要给形容词和概念加引号——写了「“耐用”“不好用”“保护”“保护有限”」，读起来像在给每个词贴标签，观感很差。去掉引号，句子照样成立。

| 不合格 | 合格 |
|---|---|
| 教材把铝的“耐用”建立在氧化膜之上，又把铝的“不好用”建立在两性之上 | 教材把铝的耐用建立在氧化膜之上，又把铝的不便建立在两性之上 |
| 把“活泼”与“耐腐蚀”这对矛盾交给学生 | 把活泼与耐腐蚀这对矛盾交给学生 |
| 前者指向“是什么”，后者指向“为什么这么用” | 前者指向是什么，后者指向为什么这样用 |

条目号、栏目标签本来就各有符号，正文再用一堆引号，整段就花了。

### 允许
- 首先／其次／再次／最后；其一／其二；前半句铺垫、后半句结论。
- 一句一段用于强调（全篇不超过两处）。

### 段落长度
每段 3–6 句。不写一句话一段的碎片，也不写超过八句的长段。

## 十、学科表述规范

- 化学式、离子符号统一用 Unicode 上下标：`H₂O`、`SO₄²⁻`、`NH₃`、`CH₃COOH`。全篇只用这一种写法，不要和 `H2O`、`SO4^2-` 混用。
- 方程式必须配平，标反应条件（`Δ`、`点燃`、`催化剂`），生成气体标 `↑`、沉淀标 `↓`；可逆反应用 `⇌`。
- **数字前后不留空格**：写 `第1课时`、`2017年版2020年修订`、`约65%`、`0.97g·cm⁻³`、`第15—17页`；单位正体，不斜体。中文与数字之间同样不加空格。
- 首次出现的缩写给全称：`阿伏加德罗常数（N_A）`。
- **不把实验现象压缩成口诀、顺口溜或单字缩写**（如"浮熔游响红"）。写现象就写完整描述，并逐条配证据与解释；只有用户明确要求时才写口诀。
- 不写"物质的量浓度单位是 mol/L 或 mol·L⁻¹ 都可以"这种含糊表述，统一用 `mol·L⁻¹`。

## 十一、交付前检查清单

逐条打勾，不合格就回去改，不要带问题交付：

1. 六部分齐全；序号从「一、」连续到底，无跳号、无重号。
2. 课标引文有出处；没有课标原文时写的是「（课标原文待补）」，不是编造的引文。
3. **教材分析有依据**：有总述逻辑、分板块、板块关系；第二段写的是本课处理，不是评价教材好坏；没有编造栏目名与实验编号。
4. **学习者分析四步齐全**：已掌握 → 范畴定位句 → 方法层面不足 → 课堂对策；不足写的是宏观能力问题，不是本课具体错点。
5. 教学目标 3–5 条；学生为隐含主语；无"使学生／让学生／培养学生／引导学生"。
6. **目标动词有层次递进**（低→高），没有四条都停在"掌握／理解"；每条有概括性，没有把课堂细节抄进目标。
7. 每条目标都能在教学过程里找到落实它的环节；反过来，每个环节都服务于某条目标。
8. **重难点全部是名词短语**，没有写成句子；难点与「学习者分析」的不足同源。
9. 教学过程是四列表格；环节数 3–5；教师列与学生列上下对位，无孤立提问或孤立回答。
10. 每个环节的设计意图 ≥1 段，且没有复述教师活动。
11. 若标注时间，各环节合计等于课时长度。
12. 化学式、方程式、离子符号、单位书写规范；方程式配平并有条件；没有把现象压缩成口诀。
13. 全篇没有「一是……二是……」式罗列，没有第九节列出的套话。
14. 板书设计只有一行占位提示，没有画图。
15. 全篇没有"（待补）"之外的空白格，没有"这里可以补充……"这类对模型说的话。
16. **课标分析只有两段**：第一段引课标要求（以学业要求为主），第二段作解读与启示；没有把本课的情境、环节与活动写进这一节。
17. **全篇少用分号与冒号**：句中并列写成句号，不用「……：一是……二是……」引出；只有条款末尾、条目号、栏目标签保留。

## 十二、高频错误对照

| 错误 | 改成 |
|---|---|
| 目标按五条素养逐条罗列 | 按教学板块分条，每条内部融素养 |
| 目标全用"掌握""理解" | 按认知／技能／体验分层选动词，低→高递进 |
| 目标写"培养学生……素养" | 写学生能做出的行为："能比较……"，或写观念结论："形成结构决定性质的观念" |
| 目标把课堂细节抄进去 | 概括到一个板块：`描述现象并解释成因` |
| 教材分析第二段批评教材 | 写本课的处理与主张 |
| 教材分析只罗列板块 | 补上板块之间的递进／对比关系 |
| 教材分析逐点罗列栏目与现象 | 每个板块一句话，只写思路与板块关系；换个实验仍成立的句子才合格 |
| 教材分析第二段写「为本课提供了可依托的骨架」这类空话 | 先总结教材的逻辑支点，再写教学中怎么做，落到做法上 |
| 学习者分析末尾写「本课据此以……开场，再以……追问」 | 学习者分析只分析学生，对策留给教学过程 |
| 发现教师活动与学生活动断链，只提不改 | 直接补上对应的提问或活动，使两列一一对应 |
| 学习者分析写本课的具体错点 | 写方法层面的宏观不足，错点归入教学难点 |
| 学习者分析缺范畴定位 | 补一句"××属于……范畴／是学生第一次……" |
| 重难点写成句子 | 名词短语：`钠与水的反应` |
| 用"一是……二是……"罗列 | "主要集中在……上。首先……其次……" |
| 把现象压缩成口诀 | 完整描述每条现象 + 逐条证据与解释 |
| 设计意图复述活动 | 写"为什么这样设计"和"学生完成了什么思维动作" |
| 环节名写成"新课讲授" | 写成"理解氢键本质，强化读图能力" |
| 把 PPT 整页文字抄进教师活动 | 压缩成一句教师的话 + 一个设问 + 学生对位 |
| 课标分析把本课情境、环节全抖出来 | 停在宏观层面：只写要求、解读与启示，设计留给教学过程 |
| 编造课标条目、教材页码、实验编号 | 留占位并向用户索取 |


## 十三、表格与课件顺序

### 标签与引号的分工

| 位置 | 符号 | 例子 |
|---|---|---|
| 教学过程的教师活动、学生活动 | **【】** | 【提问】…… 【预测】…… |
| 教材分析里引用教材栏目名 | **引号** | 教材“探究”栏目给出的顺序…… |
| 课标分析里引用课标原文 | 直接写进句子 | ……的内容要求如下：…… |

两者不可互换：教学过程用引号会丢掉标签的可扫读性，分析文字用【】会让人误以为是教学环节。

### 师生活动要对位

教师提出一个问题，学生的回答要落在**同一高度**上。做法是在较短的一列补空段落，把两条拉到大致齐平。**不要求逐行严格对齐**，错开一两行可以接受；但不要出现“教师连续十条、学生只在末尾一条”的失衡。

### 严格按课件页序

从课件转写教案时，环节的划分与顺序**必须跟课件的页序走**，不得按内容性质重新归类。课件把“为什么保存在煤油里”“久置空气中变什么”放在钠与氧气的实验之后，它们就属于那个环节，不能因为看起来像“应用”而挪到最后一节。判断依据只有一个：它在第几页。

### 环节名居中

“环节一：情境导入，明确问题”这类单元格文字，**水平与垂直都居中**，不要顶格靠左。
