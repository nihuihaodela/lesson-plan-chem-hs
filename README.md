# 高中化学教案 Skill

给 DeepSeek Harness 用的教案编写技能：按固定模板产出**结构统一、语言规范、依据可查**的高中化学教案，支持从教师的 PPT 反推教学流程，并能把 Markdown 转成符合教研习惯的 Word。

---

## 它解决什么问题

写教案最难的不是"写"，而是三件事：

1. **结构不能走样**——教学内容分析、学习者分析、教学目标、重难点、教学过程、板书设计，六部分缺一不可，顺序和标题都不能自创。
2. **依据不能编造**——课标要求什么、教材怎么编排，必须能翻到原书，不能是"看起来像课标"的句子。
3. **语言不能像 AI**——不写"培养学生的核心素养"这类空话，不用"一是……二是……三是……"式罗列，少用分号和引号。

这个技能把这三件事拆成规则和知识库，让模型照着做，而不是每次即兴发挥。

## 快速开始

```bash
git clone https://github.com/nihuihaodela/lesson-plan-chem-hs ~/.dsh/skills/lesson-plan-chem-hs
```

Windows：

```powershell
git clone https://github.com/nihuihaodela/lesson-plan-chem-hs $env:USERPROFILE\.dsh\skills\lesson-plan-chem-hs
```

装完新开一个会话，说一句"帮我写一份人教版必修一钠的教案"或"根据我这个 PPT 写教案"，技能会被自动加载。

**只在某个项目里用**：克隆到项目的 `.dsh/skills/` 下。
**给其他 agent 工具共用**：克隆到 `~/.agents/skills/`（同一份 `SKILL.md` 约定）。

## 怎么用

| 你给什么 | 它怎么走 |
|---|---|
| 课题 + 课标 | 从零写，六部分齐全 |
| 一份 PPT | 先按课件页序还原教学流程，再写教案；环节顺序严格跟页序，不自行归类 |
| 一份旧教案 | 保留结构与事实，只调表述、目标与排版 |

**输出顺序**：先给 Markdown 全文供你改，确认后再转 Word。

### 写进去的几条硬规则

- 课标分析只写两段：第一段引课标要求（以学业要求为主），第二段作宏观解读。**不把本课的情境与环节抖出来**。
- 教材分析只写两段：第一段说教材如何组织（思路与板块关系），第二段先总结再落到教学怎么做。**不逐点罗列栏目**。
- 学习者分析一段，只分析学生，**不写"本课打算怎么做"**。
- 教学目标 3–5 条，动词按认知／技能／体验分层，从低到高排布，主语是学生。
- 重难点一律名词短语。
- 少用分号与冒号，少用引号，不给形容词加引号。
- 教师与学生活动用【】标签，两列上下对位。

完整规则见 `references/写作规则.md`（13 节）与 `references/教案结构.md`。

## 课标依据从哪来

`references/知识库/` 里是《普通高中化学课程标准（2017 年版 2020 年修订）》的条目化摘引，每条一个编号（如 `K-B2-2.4`），带类型、原文、出处与状态。

- 写教案时先查 `课标-索引.md` 定位条目，再取原文；
- **只引状态为「已核验」的条目**，库里没有就向用户索取，不得用学科常识替代；
- 教案正文不写条目号，条目号记在交付说明的核验表里，供人抽查。

课标摘引属于引用，已注明版本与出处。

## 教材：如何自备

**本仓库不包含任何教材原文。** 教材受版权保护，需要你自己准备。

把你手上有的人教版教材转成 Markdown（PDF 转文字、或自己整理），然后：

```bash
python scripts/build-textbook.py 我的教材.md 必修第一册
```

会在 `references/知识库/教材原文/` 下生成：

```
必修第一册.md          清洗后的全文（去掉了图片外链，行号与原文一致）
必修第一册-索引.md      章 / 节 / 小节 → 行号
```

之后模型就能按索引定位，只读需要的那几百行，不必整本塞进上下文。

> `教材原文/` 已在 `.gitignore` 中排除，自备的教材不会被误提交。

**没有教材也能用**——课标库是完整的，只是教材分析会退化为"依据教材目录整理，待核对"。

## 已知边界

- **Word 版式依赖宿主**：宋体五号、Times New Roman、1.5 倍行距、四列全框线、表头跨页重复，这些是通过 DeepSeek Harness 的 Office 工具（`office_edit`／`office_render`）落地的。换到其他平台，内容能带走，版式要自己调。
- **课标覆盖范围**：必修 5 主题与选择性必修 3 模块的内容要求、教学提示、学业要求已全；学业质量水平与附录尚未录入。
- **教材结构化摘要**：仅 `教材-必修第一册.md` 的 2.1 节作为示例，其余章节未建。
- **学科范围**：高中化学，人教版本，默认新授课、45 分钟。
